First-time setup

  1. Open your Sources Ledger in Google Sheets.
  2. Extensions → Apps Script, delete whatever is there, and paste in apps-script/Code.gs. Save.
  3. Deploy → New deployment → Web app — Execute as: Me, Who has access: Anyone. Authorise when asked.
  4. Copy the Web app URL (…/exec) and paste it into step 1 above.
  5. Drop your DMS export, review the matches, write.

Want a second lock? Set SECRET: 'something-long' near the top of Code.gs and paste the same value into the site. Redeploy as a new deployment whenever you want to invalidate an old URL.

Runs entirely in your browser. Files are parsed locally; the only network call is to your own Apps Script.
